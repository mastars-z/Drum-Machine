# Drum Machine

A browser-based drum machine built with **HTML, CSS, and Vanilla JavaScript** as part of the [freeCodeCamp](https://www.freecodecamp.org/) JavaScript curriculum.

The project lets users play different drum sounds using either the on-screen drum pads or keyboard shortcuts, with a few extra interactive features.

## Features

- **Interactive Drum Pads:** Play nine different drum sounds by clicking the pads.
- **Keyboard Controls:** Trigger sounds using `Q`, `W`, `E`, `A`, `S`, `D`, `Z`, `X`, and `C`.
- **Power Toggle:** Turn the drum machine on or off.
- **Volume Control:** Adjust the sound volume using a slider.
- **Live Volume Indicator:** See the current volume percentage.
- **Custom Drumstick Cursor:** A drumstick image follows the cursor over the drum pad area.
- **Active Pad Animation:** Drum pads glow briefly when triggered.
- **Dynamic Display:** Shows the name of the sound being played.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
